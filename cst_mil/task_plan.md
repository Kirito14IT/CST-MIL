# Task Plan: CST-MIL 小规模 SCCD 实验与进度报告

## Goal

在不使用大语言模型、预训练语言模型或 GPU 的前提下，实现可复现的 CST-MIL 会话风险检测流程，完成一次固定的 300 会话实验，并把真实证据写入根目录的《任务进度报告.md》。

## Phases

- [x] Phase 1: 锁定任务范围、证据口径与验收条件
- [x] Phase 2: 建立项目骨架、环境与受保护文件快照
- [x] Phase 3: 下载并清洗固定版本 SCCD，生成 `post_id` 会话级无交叉划分
- [x] Phase 4: 实现 CST-MIL、命令行接口与单元测试
- [x] Phase 5: 运行唯一一次正式训练与评估，生成分析产物
- [x] Phase 6: 填写进度报告并完成复现、完整性与未改动验证

## Fixed Decisions

- 方法：CST-MIL（字符风险通道 + 8 主题 MiniBatchNMF + 弱监督多实例学习 + 会话级线性分类器）。
- 数据：SCCD 官方提交 `cf4015b802cabd651885211dc382152c1a270c31`，首轮只使用 `posts.csv` 与 `comments.csv`。
- 样本：固定种子 42，150 个 CB 与 150 个 Non-CB 会话；训练/验证/测试为 180/60/60。
- 监督：模型训练只读取会话级标签；评论级标签仅用于测试集证据定位评估。
- 结论：本轮是一次小规模可行性实验，不做基线性能比较或显著性优越结论。
- 保护范围：不修改 `任务要求.docx`、`任务要求 - 副本.docx` 与 `baseline/`。
